# Provenance and attribution

This standalone showcase is adapted from the recovered Polytracker source snapshot.
It preserves selected engineering patterns from the production-oriented implementation,
including typed domain models, per-record ingestion handling, feature interfaces, and
bounded market-event processing.

The showcase is intentionally not a copy of the production application. It removes
network clients, database access, deployment configuration, credentials, user data,
private Lineups, Telegram integration, and proprietary scoring logic. The scoring layer
is replaced with small, clearly labeled demonstration features.
